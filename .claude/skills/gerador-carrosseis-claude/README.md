# Gerador de Carrosseis para Claude

Esta Skill configura o Claude para criar carrosseis por conversa.

Use o prompt:

> Configure meu gerador de carrosseis. Sou leigo e quero fazer tudo por conversa.

Depois envie sua marca, publico, tom, CTA e referencias visuais quando solicitado.

## O que ela entrega

- Perfil de marca.
- Roteiro slide a slide.
- Legenda.
- Direcao visual.
- Template de conteudo.
- Checklist de revisao.

## Limite importante

Esta versao e uma Skill para Claude. Ela nao e um plugin do Codex e nao publica automaticamente.
