# Checklist de Revisao do Carrossel

## Sequencia

- [ ] O slide 1 para o dedo.
- [ ] Cada slide tem uma ideia central.
- [ ] A ordem cria curiosidade para o proximo slide.
- [ ] O pico de valor aparece antes do CTA.
- [ ] O CTA e simples de executar.

## Texto

- [ ] Headline curta.
- [ ] Corpo legivel em celular.
- [ ] Sem jargao desnecessario.
- [ ] Sem promessa magica.
- [ ] Ortografia, acentos e nomes revisados.

## Visual

- [ ] Todos os slides tem imagem, direcao visual ou excecao justificada.
- [ ] Nenhum slide ficou vazio, preto ou sem carregar.
- [ ] Contraste suficiente.
- [ ] Logo correta para o fundo.
- [ ] Sem box branco atras da marca, salvo escolha da propria marca.

## Entrega

- [ ] Legenda complementa o carrossel.
- [ ] CTA da legenda bate com o ultimo slide.
- [ ] Fonte ou data registrada quando houver dados atuais.
- [ ] Se houver exportacao, revisar capa, slide mais denso e CTA em tamanho real.
