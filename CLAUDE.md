# magic-prompt

This project uses the [Everything Claude Code (ECC)](https://github.com/affaan-m/ECC) toolkit, installed
under `.claude/` (full profile — agents, skills, commands, rules, hooks, and MCP configs).

- Agent roster and usage guidance: `.claude/AGENTS.md`
- Rules (coding style, git workflow, testing, security, etc.): `.claude/rules/ecc/`
- Skills: `.claude/skills/`
- Slash commands: `.claude/commands/`
- Hook definitions (not yet wired into `settings.json` — see `.claude/hooks/README.md` before enabling): `.claude/hooks/hooks.json`
- MCP server templates: `.claude/mcp-configs/`
